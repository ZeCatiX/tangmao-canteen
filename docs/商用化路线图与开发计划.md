## 2. 目标与验收总纲

**北极星目标**：单店单时段真实试用，首批 30-50 笔真实订单全流程跑通（点餐→厨房→完成→结算对账），并收集 50+ 条真实顾客反馈。

**三类角色验收标准**：

| 角色 | 验收标准（全部可验证） |
|---|---|
| 顾客 | 扫码→点餐→付款→吃饭，全程 ≤3 分钟、无需注册、无需装 App；断网/慢网下菜单仍可浏览 |
| 商家 | 老板不看文档能独立完成：改价格、标售罄、看当日单量、对账一笔订单 |
| 管理者 | 连续 7 天服务器无人工干预存活；备份恢复演练通过；有任意异常时能在 10 分钟内收到通知 |

## 4. 阶段计划（详）

### 阶段 0 · 上线准备收尾（0.5 周，4 条线并行）

| 任务 | 内容/涉及文件 | 验收 |
|---|---|---|
| T0.1 pm2 部署 | `pm2 start server.js --name tangmao`；`pm2 startup` 自启；`max_memory_restart: 512M` | kill 进程后 5 秒自愈；机器重启自动拉起 |
| T0.2 日志轮转 | pm2-logrotate 按天、保留 14 份；访问/错误分离 | 日志目录不再无限增长 |
| T0.3 HTTPS | 域名解析 → certbot Let's Encrypt → Nginx 301 强制跳转 → 反代 3000 | 扫码 HTTPS 全绿、锁标有效 |
| T0.4 备份+演练 | cron 3:00 `pg_dump tangmao \| gzip`，保留 30 天；uploads/ 每日同步 | 恢复演练：从备份还原到临时库并校验行数 |
| T0.5 密码核实 | 查 users.password 字段格式；如明文 → bcrypt 迁移脚本 + 登录兼容切换 | 新旧密码均可登录，新写入全为哈希 |
| T0.6 对账规则（产品决策）| 方案 A：订单页展示静态收款码+后台"已收款"标记；方案 B：收银台扫码枪确认 | 老板签字确认其一 |
