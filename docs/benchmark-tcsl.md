# 对标分析：唐猫庭院系统 vs 天财商龙

> 对标对象：天财商龙（tcsl.com.cn，天津，餐饮数字化 SaaS 约 27 年，2025-05 获拉卡拉 2.5 亿入股，推"青橙餐饮云"）。
> 定位：它是目标、是对手、也可能是终局的买方。**第一步是对标摸底**——本文档即摸底结果。
> 维护纪律：产品认知有更新时更新本文档；功能落地后同步刷新"差距"列。

## 一、双方体量与赛道位置（先说清楚差距的性质）

| | 天财商龙 | 我们 |
|---|---|---|
| 形态 | 成熟商业 SaaS，6 大产品体系，POS 硬件生态 | 单店 Web 应用（Node/Express + PG + ML） |
| 客群 | 正餐/快餐/火锅/团餐/酒店/海外，连锁为主 | 唐猫庭院单店（未上线，测试数据） |
| 核心壁垒 | 27 年行业流程沉淀、渠道、硬件、支付闭环 | AI 推荐（口味建模+梯度提升）、席面生成、轻量易改 |

**结论：正面复刻它的 6 大体系没有意义也追不上。对标的正确姿势是——把"单店数字化点餐 + AI 推荐"这条我们所在的窄道打穿，其余能力按"需不需要"而非"它有没有"来决策。**

## 二、六域对照（商龙 6 大体系 vs 我们现状）

### 1. 餐饮管理系统（POS/点餐/出品）
| 商龙产品 | 我们现状 | 差距 | 策略 |
|---|---|---|---|
| 中餐/快餐 POS 收银 | 无收银，仅"去结算"模拟下单 | 🔴 缺失 | 明确不做收银——支付是商龙腹地，接盘场景下订单应走商龙 |
| 手机/扫码点餐 | ✅ Web 扫码点餐+桌号+外卖标签 | 🟡 接近 | 守住，体验做好（已是主战场） |
| 智能 KDS 出品 | ✅ kitchen.html 看板（状态流转/自动刷新/当日归档） | 🟡 轻量版 | 够用；可补"叫号/催菜"但优先级低 |
| 出餐叫号/智能预定/排班/提成/酒水寄存 | 无 | 🔴 缺失 | P2 不做（单店用不上） |

### 2. 会员营销（商龙最强域）
| 商龙产品 | 我们现状 | 差距 | 策略 |
|---|---|---|---|
| 会员体系/储值/权益卡 | 有用户注册登录（JWT），无储值等级 | 🔴 缺失 | P1：单店版"常客记忆"可做（与口味建模天然结合），不做储值 |
| 优惠券/拼团/红包/营销日历 | 无 | 🔴 缺失 | P2 不做——营销玩法是连锁需求，单店ROI低 |
| 智能标签/精准分群 | ✅ 偏好分布分析页 + 用户口味画像 | 🟡 自有版本 | 我们的画像基于口味问卷+行为，方向不同但同源，可深化 |

### 3. 智慧餐厅（扫码点餐场景）
| 商龙产品 | 我们现状 | 差距 | 策略 |
|---|---|---|---|
| 扫码点餐 | ✅ 全链路（菜单/购物车/结算/桌号） | 🟢 持平甚至体验更好（AI推荐、中英双语、深色模式、无障碍） | **主战场，持续投入** |
| AI 推荐 | ✅ **独有**：单菜推荐(ML)+一席成宴席面+换一批+口味问卷+反馈重训闭环 | 🟢 **领先（商龙无此为核心）** | **核心资产，加速拉开差距** |
| 聚合外卖 | 无 | 🔴 缺失 | P2（依赖三方平台，非自研可控） |
| 桌边付/电子发票/桌访满意度 | 部分：反馈系统有（2595条），支付/发票无 | 🟡 半缺 | 反馈闭环已有且喂模型——守住；支付同上不做 |
| 智能桌牌/硬件 | 无 | 🔴 缺失 | P2 不做（硬件非我们赛道） |

### 4. 供应链管理
| 商龙产品 | 我们现状 | 差距 | 策略 |
|---|---|---|---|
| 采购/库存/成本/连锁配送 | 无；dishes.is_sold_out 字段刚修通（可手动售罄） | 🔴 缺失 | P1 最小版：售罄自动流转（菜卖完自动置 sold_out）可接；完整供应链不做 |

### 5. 运营与决策
| 商龙产品 | 我们现状 | 差距 | 策略 |
|---|---|---|---|
| 龙决策（经营决策闭环） | ✅ 雏形：营业日报、数据分析、模型管理（重训/特征重要性/metrics 历史） | 🟡 雏形对成熟 | 我们的差异化=**把 AI 模型效果纳入决策**（它没有）；报表口径可日后对齐商龙便于对接 |
| 人事/财务/财务中台 | 无 | 🔴 缺失 | P2 不做 |

### 6. 酒店管理
- 🔴 完全不相关，不做。

## 三、差距清单汇总（按行动优先级）

**P0 — 正在做/必须守住（我们所在窄道）**
1. 点餐全链体验：菜单/筛选/购物车/结算/厨房流转（本轮已修 is_sold_out 缺列+分类对齐，117 测试全绿）
2. AI 推荐深挖：席面推荐、口味建模、反馈重训闭环——这是对标叙事的核心资产
3. 真实灰度：让唐猫庭院以"AI 推荐入口"身份真实跑起来（订单可仍走商龙收银），积累口味-订单-反馈数据

**P1 — 单店尺度内有价值（2026-11-03 全部落地 ✅）**
1. ✅ 售罄自动流转（估清：备量/扣减/卖完自动售罄/日切，`ba9efca`）
2. ✅ 常客记忆（visit-summary 第 N 次光临 + 上次点过的菜欢迎条 + 一键再来一单，`a3ab22f`）
3. ✅ 催菜（顾客催菜按钮 10 分钟门槛 30 分钟冷却 + 厨房看板红框🔥徽章置顶，`a3ab22f`）
4. ✅ 营业日报口径对齐商龙（翻台率/桌均/环比昨日，`1884fd5`）
5. ✅ 客群标签（常客/回头客/新客三档 + 口味分布 + 常客 TOP，对标商龙六大智能标签，`a3ab22f`）

> **2026-11-05 验证升级**：P1 五项已通过**两轮模拟真实用户点击测试**（IAB 手机视口全旅程 + 真 Chrome puppeteer 回归）端到端复核——估清卖完自动售罄（看板完成流转实测）、常客"再来一单"购物车填充、催菜倒计时灰置态、营业日报口径（122 元/翻台率 3%/动销 Top20 与订单逐项吻合）、AI 推荐按偏好打分（匹配度 84.2% 递减）+ 评分落库实时联动热门排行。CI 全绿（tangmao_test seed + 117 API + 300+ 全量）。P0-1/P0-2 的"守住/拉开"项同步受益于：分类改名漂移三处收口（种子/席面池/启动迁移）+ 弹层规格同步修复 + 过期 token 登录回归钉死。

**P2 — 明确不做（接盘叙事下反而是优点：不越界）**
收银/支付/发票、储值营销玩法、完整供应链、POS/桌牌/机器人硬件、连锁总部、财务人事、酒店。

## 四、对标叙事一句话

> 唐猫庭院系统 = 商龙体系之上的 **AI 点餐增值层**：扫码点餐体验对齐、AI 推荐独家领先、反馈闭环自进化；不碰收银供应链，与商龙是互补而非替代——竞争在入口层，合作在结算层。
