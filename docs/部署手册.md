# 唐猫庭院 · 部署手册（生产环境）

> 适用：将本系统部署到公网/校内服务器，启用 HTTPS 与进程守护。
> 前置：一台服务器（Linux 推荐 / Windows 亦可）、一个已解析到该服务器的域名、Node 20+、PostgreSQL 17。

---

## 1. 拉取代码与环境

```bash
git clone <仓库地址> tangmao && cd tangmao
npm ci                      # 按 package-lock 安装依赖
cp .env.production.example .env
```

**逐项填写 .env（关键项）**：

| 项 | 要求 |
|---|---|
| JWT_SECRET | 64 位十六进制随机串，生成：`node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"` |
| TABLE_SECRET | 32 位以上随机串 |
| ADMIN_USER / ADMIN_PASS | 管理员账号；密码 ≥12 位强密码（server.js 会校验强度）|
| RATE_LIMIT_WINDOW_MS / RATE_LIMIT_MAX | 900000 / 100（生产值，勿用测试的宽松值）|
| LOGIN_RATE_LIMIT_MAX 等 | 按 .env.production.example 的生产建议值 |
| PG_* | 生产库连接信息 |

> ⚠️ server.js 在 NODE_ENV=production 下会**校验★项**：密钥弱/限流过宽会**拒绝启动**（这是防呆设计，日志会给出原因）。

## 2. 启动与进程守护

```bash
npm ci
pm2 start ecosystem.config.js     # 按 ecosystem.config.js 启动
pm2 save                          # 保存进程列表
pm2 startup                       # 按输出提示执行一条命令 = 开机自启
pm2 install pm2-logrotate         # 日志轮转
pm2 set pm2-logrotate:max_size 50M
pm2 set pm2-logrotate:retain 14
```

验证：`curl -I http://localhost:3000` 返回 200/301；`pm2 list` 状态 online。

**守护自愈已验证**：强杀应用子进程后 pm2 约 3 秒自动拉起（本阶段实测）。

## 3. HTTPS（Nginx + certbot）

```nginx
server {
    listen 80;
    server_name 唐猫庭院域名;
    return 301 https://$host$request_uri;
}
server {
    listen 443 ssl;
    server_name 唐猫庭院域名;
    ssl_certificate     /etc/letsencrypt/live/域名/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/域名/privkey.pem;
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

```bash
sudo certbot --nginx -d 域名       # 自动签发+续期（90 天周期自动续）
```

**防火墙**：只开放 80/443；3000 端口与 PostgreSQL 5432 **不得**对公网开放。

## 4. 数据库备份

```bash
# cron（每天 03:00）：路径按实际调整
0 3 * * * cd /path/to/tangmao && bash scripts/backup_db.sh >> logs/backup.log 2>&1
```

- 脚本自动保留最近 30 份，自动清理更旧备份
- **恢复演练**（上线前必做一次并记录）：
  1. `createdb tangmao_restore_test`
  2. `gunzip -c backups/<最新>.sql.gz | psql -d tangmao_restore_test`
  3. 校验行数与主库一致（dishes/orders/users/feedback 四表）
  4. `dropdb tangmao_restore_test`
- 本阶段已完成首次演练：备份 189KB → 恢复后 dishes=114/orders=272/users=1365/feedback=644 全部一致 ✓

|---|---|---|---|
| A · 收款码+人工对账 | 订单完成页展示门店收款码；收银/老板收款后在 admin 该订单标记"已收款"；日终按订单总额与收款流水核对 | 零开发成本、当天可用 | 人工标记可能漏标；无支付状态自动校验 |
