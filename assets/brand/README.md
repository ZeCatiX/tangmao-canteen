# 唐猫庭院 · AI 生图规范

品牌形象基准：官方菜单唐猫插画（`tangcat-official.png`）。所有 AI 生成图片必须与它实时对比校验。

## 资产

| 文件 | 用途 |
|---|---|
| `tangcat-official.png` | 官方原稿（1841×869）——风格唯一基准，勿修改 |
| `gen_images/tangcat-official-crop.png` | 裁剪合规版（1738×869，≤2:1）——`--edit` 的 `--image` 参数用这个 |

## 生图命令模板

```bash
python "C:\Users\Lenovo\.agents\skills\sensenova-image\scripts\gen.py" --edit \
  --image "D:\食堂网页\gen_images\tangcat-official-crop.png" \
  --prompt "<场景描述> + 下方关键词配方" \
  --model fast \        # 草稿先 fast；样貌确认后换 lite 出定稿
  --size 2048x2048 --no-watermark --output-dir "D:\食堂网页\gen_images"
```

## Prompt 关键词配方

**必须写**（识别性特征，缺一就不像）：
- 拟人化白猫站立，**头大身圆的幼态比例（头约占一半），像参考图里提灯笼的小孩猫**
- **闭眼微笑**：两道细长下弯弧线，不要画睁眼
- 额心红色小花钿；**头侧金色小花+红色垂坠发饰**（官方白猫标志性细节）
- 粉色内耳；粉色腮红晕
- 唐制齐胸襦裙（米白上衫+红黄渐变长裙，裙面金色团花纹样），肩绕橙红披帛飘带
- 手绘水彩质感，细线描边，奶油色背景

**禁止写**（踩过的坑）：
- ~~"身体修长、像穿着唐装的小人"~~ → lite 会忠实执行，头画小、脸人化，猫感尽失
- ~~盘扣/立领~~ → 那是明清元素，唐制襦裙无盘扣

**模型选择**：样貌以 **fast** 为准（lite 指令遵循强，prompt 有偏差会被放大）；fast 确认样貌后、且需要更高细节时才上 lite，出完必须再和参考图对比一次。

## 生成后校验清单（每次必做，与参考图并排对比）

1. 头身比：大头幼态（头约占一半），不是修长小人
2. 脸：猫的圆脸结构，闭眼笑弧，不是人脸眉眼
3. 花钿（额心红）+ 红坠发饰（头侧）在位
4. 耳内粉、腮红晕在位
5. 服装：唐制齐胸襦裙+披帛，无盘扣
6. 线条与配色：手绘水彩、红金米白体系

任何一项不合格 → 调整 prompt 重新生成，不要将就。

## 归档规则

- 草稿/过程图：`gen_images/`（已 gitignore，可随时清理）
- 定稿：`assets/illustrations/<用途>-<描述>.png`（2048 源文件）+ 同名 `.webp`（800px 网页版，sharp 生成）
