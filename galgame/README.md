# 唐猫庭院 · 千年陕菜谭（galgame）

唐猫庭院餐厅 × 点餐推荐系统的宣传视觉小说。玩家在大唐不夜城的夜里被一只系铃铛的白猫引入庭院，遇见看板猫娘「唐猫」——一夜招牌菜、一桌 AI 方案、一场老饕小考、一段雨夜里的七年前传说。第一夜的回答决定次日走哪条路线，好感与选择导向六种结局。

## 玩法

- 点击画面推进对话，**空格 / 回车**同样有效
- **三条次日路线**（带朋友来 / 一个人来 / 只是路过），各自专属剧情
- **两个小游戏**：猜菜名大会（看 CG 答题，即时判分）＋ 预算挑战（真实菜价配一桌，实时合计、超支拦截、荤素汤结构评价）
- **两条支线**：后厨偷看（葫芦鸡三道工序）、拼桌西安大爷（七年回头客 + 雨夜捡猫传闻）
- 好感度系统：选项/答题/配桌都会累积羁绊，解锁雨夜完整剧情与结局分流
- **六种结局 + 一个沉默结局**：🌶️ 扶墙而出 / 🌙 一面之缘 / 🏮 回头客 / 🐾 千年之约 / 🫖 灯下知己 / 🔔 铃铛（隐藏）/ 😿 未说出口的抱歉（雨夜说错话且未道歉）
- 自动播放、快进、对话记录、自动存档（标题「继续旅程」恢复）
- 结局持久收集，全结局达成有彩蛋

## 运行

零依赖、纯前端（HTML + CSS + 原生 JS），两种方式任选：

```bash
# 1) 直接双击打开
galgame/index.html

# 2) 经由点餐系统服务器（推荐，可跳转真实点餐页）
#    服务运行时访问：
http://localhost:3000/galgame/
```

## 剧情扩展

`js/story.js` 的 `SCRIPT` 数组即全部剧本，命令格式：

| 命令 | 作用 |
| --- | --- |
| `say` | 对白（who: narr/me/唐猫/掌柜/同学/白猫/大爷；expr 切换立绘表情） |
| `choice` | 选项（aff 加好感，flag 记标记，goto 跳标签） |
| `dish` / `card` | 菜品 CG 卡 / 通用卡片（一桌菜方案、口味档案、宣传页） |
| `quiz` / `budget` | 猜菜名小游戏 / 预算挑战小游戏（数据见 `QUIZZES` / `BUDGET_GAME`） |
| `chapter` / `bg` / `bgm` / `show` / `hide` | 章节大字 / 背景 / 音乐 / 立绘 |
| `nameinput` / `set` / `if` / `jump` / `ending` | 名字输入 / 状态（aff 或 flag=value）/ 分支（affGte 或 flagHas）/ 跳转 / 结局 |

新增菜品 CG：在 `art.js` 的 `DISHES` 加 SVG、`story.js` 的 `DISH_INFO` 加资料即可。

## 内容口径

**世界观分隔与创作红线（2026-10-26 用户口径）**：游戏世界观与真实门店的经营处境完全分隔——**不提**开业年份（2019）、经营年数（"七年"）、疫情/堂食关停等任何现实经营史；剧本时间线一律模糊化（"开张那年""很多年前""这些年"）。可以提：真实的菜品；可以参考：真实的餐厅场景布局。**创作红线**：① 不做「本地熟客 vs 外来游客」的客源叙事（掉价、有负面影响）——待客表达一律中性："客不分远近，推开门就是庭院的人"；菜单文档中"十桌老顾客八桌本地人/本地人的待客小宴"等话术不引用、不展开；剧情角色（大爷/李叔）只作为普通老主顾的个人故事呈现，不贴"本地熟客"标签。② **剧情内不做刻意宣传**：不逐条罗列四大承诺/荣誉清单，不说"真实功能"等打破第四面墙的话，不喊口号；荣誉、承诺、门店信息只在每个结局后的宣传卡（宣传品本体区）呈现；系统功能（口味档案/AI 一桌菜）只借角色之口以"同行/电子猫"的口吻自然带出。

**画风口径（2026-10-25 用户定调）**：整体为动画风 galgame——场景背景为**动画平涂水彩**（吉卜力感，色块干净、笔触柔和、无厚涂写实感），角色立绘为**赛璐璐动画上色**，两者同屏统一；CSS 层仅做轻调（微收饱和/对比+极轻颗粒）保持通透，不做胶片重调。符合唐猫庭院可爱温馨的唐风气质。

菜品、价格、门店、四大服务承诺与荣誉均出自 `唐猫庭院_完整菜单.md`（带辣菜品数 27 为数据库实测：微辣19+中辣7+重辣1，不含饮品主食）；「口味档案」「AI 一桌菜」「评分反馈让推荐更懂你」「饮品主食不参与推荐」对应点餐系统真实功能（HistGradientBoosting 梯度提升推荐）。七年前雨夜白猫的来历为剧情创作（传说框架），非店史陈述。`images/` 下剧情 CG ×3（雨夜/系铃铛/烟花）、8 张场景背景（街道/黎明/庭院/餐桌/烟花/雨夜/白天/后厨）、标题主视觉、8 张猫娘表情差分立绘与序章白猫立绘（参照项目品牌白猫形象）均由 SenseNova U1.5 生成并逐张人工验收（绿幕生成→despill 抠图→webp 透明底）；13 张菜品 CG 仍为代码生成。菜品数据、菜单与图片素材由唐猫庭院提供。MIT License。
