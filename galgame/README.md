# 唐猫庭院 · 千年陕菜谭（galgame）

唐猫庭院餐厅 × 点餐推荐系统的宣传视觉小说。玩家在大唐不夜城的夜里被一只系铃铛的白猫引入庭院，遇见看板猫娘「唐猫」——一夜招牌菜、一桌 AI 方案、一场老饕小考、一段雨夜里的七年前传说。第一夜的回答决定次日走哪条路线，好感与选择导向六种结局。

## 玩法

- 点击画面推进对话，**空格 / 回车**同样有效
- **三条次日路线**（带朋友来 / 一个人来 / 只是路过），各自专属剧情
- **两个小游戏**：猜菜名大会（看 CG 答题，即时判分）＋ 预算挑战（真实菜价配一桌，实时合计、超支拦截、荤素汤结构评价）
- **两条支线**：后厨偷看（葫芦鸡三道工序）、拼桌西安大爷（七年回头客 + 雨夜捡猫传闻）
- 好感度系统：选项/答题/配桌都会累积羁绊，解锁雨夜完整剧情与结局分流
- **六种结局 + 一个沉默结局**：🌶️ 扶墙而出 / 🌙 一面之缘 / 🏮 回头客 / 🐾 千年之约 / 🫖 灯下知己 / 🔔 铃铛（隐藏）/ 😿 未说出口的抱歉（雨夜说错话且未道歉）
- 自动播放、快进、对话记录、自动存档（标题「继续旅程」恢复）
- 结局持久收集，全结局达成有彩蛋

## 运行

零依赖、纯前端（HTML + CSS + 原生 JS），两种方式任选：

```bash
# 1) 直接双击打开
galgame/index.html

# 2) 经由点餐系统服务器（推荐，可跳转真实点餐页）
#    服务运行时访问：
http://localhost:3000/galgame/
```

## 剧情扩展

`js/story.js` 的 `SCRIPT` 数组即全部剧本，命令格式：

| 命令 | 作用 |
| --- | --- |
| `say` | 对白（who: narr/me/唐猫/掌柜/同学/白猫/大爷；expr 切换立绘表情） |
| `choice` | 选项（aff 加好感，flag 记标记，goto 跳标签） |
| `dish` / `card` | 菜品 CG 卡 / 通用卡片（一桌菜方案、口味档案、宣传页） |
| `quiz` / `budget` | 猜菜名小游戏 / 预算挑战小游戏（数据见 `QUIZZES` / `BUDGET_GAME`） |
| `chapter` / `bg` / `bgm` / `show` / `hide` | 章节大字 / 背景 / 音乐 / 立绘 |
| `nameinput` / `set` / `if` / `jump` / `ending` | 名字输入 / 状态（aff 或 flag=value）/ 分支（affGte 或 flagHas）/ 跳转 / 结局 |

新增菜品 CG：在 `art.js` 的 `DISHES` 加 SVG、`story.js` 的 `DISH_INFO` 加资料即可。

## 内容口径

**餐厅定位（2026-10-25 用户口径，优先于菜单文档话术）**：唐猫庭院 2019 年开业，位于大雁塔/小寨游客区，是主要服务游客的网红陕菜店；本地熟客是"正在攒的珍贵少数"而非基本盘。菜单文档中"十桌老顾客八桌本地人/从网红店到本地头牌"为店家宣传愿景，剧情以其为目标处理，不作现状陈述；"七年"一律锚定为开业年限（2019→2026）。

菜品、价格、门店、四大服务承诺与荣誉均出自 `唐猫庭院_完整菜单.md`（带辣菜品数 27 为数据库实测：微辣19+中辣7+重辣1，不含饮品主食）；「口味档案」「AI 一桌菜」「评分反馈让推荐更懂你」「饮品主食不参与推荐」对应点餐系统真实功能（HistGradientBoosting 梯度提升推荐）。七年前雨夜白猫的来历为剧情创作（传说框架），非店史陈述。`images/` 下 3 张剧情 CG（雨夜/系铃铛/烟花）由 SenseNova U1.5 生成并经人工验收，其余美术均为代码生成。菜品数据、菜单与图片素材由唐猫庭院提供。MIT License。
