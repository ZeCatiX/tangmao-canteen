# 唐猫庭院 · 千年陕菜谭（galgame）

唐猫庭院餐厅 × 点餐推荐系统的宣传视觉小说。玩家在大唐不夜城的夜里被一只系铃铛的白猫引入庭院，遇见看板猫娘「唐猫」，经历招牌菜、口味档案、AI 一桌菜、四大服务承诺的完整待客体验，最终走向四种结局之一。

## 玩法

- 点击画面推进对话，**空格 / 回车**同样有效
- 选项影响看板猫好感度，决定结局：🌶️ 扶墙而出 / 🌙 一面之缘 / 🏮 回头客 / 🐾 千年之约
- 自动播放、快进、对话记录、自动存档（关闭页面后从标题「继续旅程」恢复）
- 结局持久收集，全结局达成有彩蛋

## 运行

零依赖、纯前端（HTML + CSS + 原生 JS），两种方式任选：

```bash
# 1) 直接双击打开
galgame/index.html

# 2) 经由点餐系统服务器（推荐，可跳转真实点餐页）
#    服务运行时访问：
http://localhost:3000/galgame/
```

## 结构

```text
galgame/
├── index.html   # 页面骨架与 UI
├── style.css    # 唐风主题样式（对话框/标题画面/卡片/动画）
├── README.md
└── js/
    ├── art.js     # 全部美术：SVG 立绘(14表情)/白猫/5场景背景/6张菜品CG
    ├── audio.js   # WebAudio 实时合成五声音阶 BGM×5 + 音效×5（无音频文件）
    ├── story.js   # 剧本数据：对白/分支/4结局 + 真实菜单数据卡片
    └── engine.js  # VN 引擎：打字机/选项/好感度/存档/结局收集
```

## 剧情扩展

`js/story.js` 的 `SCRIPT` 数组即全部剧本，命令格式：

| 命令 | 作用 |
| --- | --- |
| `say` | 对白（who: narr/me/唐猫/掌柜/同学/白猫；expr 切换立绘表情） |
| `choice` | 选项（aff 加好感，flag 记标记，goto 跳标签） |
| `dish` / `card` | 菜品 CG 卡 / 通用卡片（一桌菜方案、口味档案、宣传页） |
| `chapter` / `bg` / `bgm` / `show` / `hide` | 章节大字 / 背景 / 音乐 / 立绘 |
| `nameinput` / `set` / `if` / `jump` / `ending` | 名字输入 / 状态 / 分支 / 结局 |

新增菜品 CG：在 `art.js` 的 `DISHES` 加 SVG、`story.js` 的 `DISH_INFO` 加资料即可。
